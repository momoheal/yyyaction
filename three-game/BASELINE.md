# 《鸭鸭鸭行动》3D 版玩法对照

本计划采用 Quick 优化网页版作为全量对照。原版档案固定为仓库提交 `9a67b39` 的 `docs/release/04-quick-optimized.html`。首个 3D 切片从 TypeScript 网页版接入，镜头固定向下倾斜 45°，地图北方朝屏幕上方。玩法仍以原版地面坐标计算距离、方向和碰撞。

## 首个切片

先用独立网页工程走通大厅 → 训练 → 结算，再进入鸭鸭岛验证正式行动。训练按代码顺序检查：清理两只小鸡或提前拿枪 → 消灭军械室附近两名鸭匪 → 搜补给 → 击退撤离点两名伏兵 → 在圈内完成撤离。提前搜箱也要能继续。

当前复用六图源码，因此已有战区可被选中或生成的事实，只说明有对应逻辑入口。每个战区的 3D 表现、Quick 差异和实际通关需要分别记录。冰火空军基地、其他首领扩展招式、出生点补给和专属掉落属于后续 Quick 对齐范围。

## 验收记录

本轮试玩美术以 Quick 的地图生成函数和道具图形为基准。货港用缆绳和浮标，工厂用炉口、管线和铁锭，孵化场用蛋巢和孢子囊，哨站用冰晶塔、雪堆和雷达，陵寝用金鸭像、喷泉、石狮和宫灯。宝箱和金币堆分别建模，沿用已有搜刮对象。室内地块明确启用屋顶，进屋隐藏，室外遮挡角色时淡显。实体道具按占地注册移动碰撞，在地图生成时让开现有掩体和关键站位。调试模式默认开启。

| 项目 | 通过条件 |
| --- | --- |
| 操控与视野 | 键鼠和触屏分别验证。人物沿输入的屏幕方向移动，斜向保持原版地面速度；准星、投掷目标和角色朝向对应同一地面点。记录贴墙、屏幕边缘、缩放后的结果。 |
| 地图与交战 | 按同一建筑、出生区和撤离区对照。逐项检查移动阻挡、子弹阻挡和敌人视线；装饰物的立体高度不能改变原有可通行路线。人物被前景挡住时仍能读懂位置与技能预警。 |
| 单局结算 | 分别完成训练、正式撤离、死亡及超时。记录出击前、局内和结算后的库存、消耗、带回物、撤离次数与排行榜，核对每次结算只执行一次。 |
| 解锁与掉落 | 用训练记录和门槛前后各一份存档检查所有战区入口。首领必掉物按原版条件核对；随机物资按掉落池、数量和权重核对，保留实际抽样记录。 |
| Quick 新内容 | 从快照选择空军基地，复核双首领技能、可破坏冰墙、出生点补给箱与阶段切换。将同一遭遇的原版和 3D 录屏连同可读代码位置附在验收记录中。 |

项目主控记录所对照的快照版本及未决差异。玩法负责人提供原版证据，3D 负责人交付对应画面及交互，独立验收负责人记录复现步骤、设备、预期与实际结果。完成实测后再更新各战区的状态。
