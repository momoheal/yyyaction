# 1.1.6 版真实截图（小游戏本体渲染）

全部为 **1280×720 PNG**，由 `minigame-opt/dist/game.js`（与线上同一份代码）在浏览器里以 `wx` 垫片运行后逐帧截取，
不是网页版、不是拼图、无二维码、无联系方式、无调试信息。可直接用于提审参考、商店/宣传物料。

| 文件 | 内容 |
| --- | --- |
| 01-lobby.png | 大厅：三张入口卡（角色 / 战区 / 装备）+ 顶部统计 + 开始行动 |
| 02-characters.png | 选角色：小黄（选中）/ 铁头 / 快羽，含移速护甲与定位说明 |
| 03-maps.png | 选战区：七张战区卡，含首领头像与难度 |
| 04-loadout.png | 选装备：跑刀 / 突击 / 重装，三档背包图标 |
| 05-combat.png | 战局：鸭鸭岛实机画面，任务目标与 HUD |
| 06-combat-fight.png | 交火：与鸭匪交战、击杀提示、首领血条 |
| 07-combat-move.png | 移动搜刮：建筑区、物资箱与撤离点指示 |

## 说明

- 截图里的存档是预置的演示进度（仓库 ¥486,000 / 出击 23 / 撤离 74%），只是让画面呈现成品状态，不影响任何线上数据。
- 战斗画面中部的操作提示面板是首次进入战局的新手引导，属游戏内真实 UI。
- **结算页暂缺**：需要真正打完一局（撤离或阵亡）才会出现，自动化难以稳定触发。如需要，玩一局后截图发我，或我再单独做一个驱动版本。

## 旧截图在哪

`art_assets/screenshots/` 根目录下的 20 张是 **1.1.2 时期的网页版（React 界面）** 截图，
界面风格与小游戏现在的 Canvas UI 不一致，**提审/宣传请使用本目录 `1.1.6/` 这一套**。

## 重新生成

```bash
npm run build:minigame-opt          # 先构建最新包
node .workbuddy/mini-shot/shoot.mjs # 驱动真实包截图
```

脚本在 `.workbuddy/mini-shot/`：`harness.html` 提供 `wx` 运行时垫片与预置存档，`shoot.mjs` 通过 CDP 派发触摸并截图。
