# 名称查重与备选方案

## 结论

正式名称沿用 **「鸭鸭鸭行动」**。备案名、账号主体、提审名三处必须完全一致，注册后不要改名。

## 我不能替你做的事

名称是否已被占用，只有在你登录微信公众平台、用小游戏类目账号进入名称设置页才能查到（查重结果实时变化，且我没有你的账号权限）。下面给你两步操作和备选名。

## 查重步骤

1. 登录 <https://mp.weixin.qq.com> → 设置 → 基本设置 → 名称（小游戏账号需在「游戏设置」入口）。
2. 输入 `鸭鸭鸭行动`，点「检测」。
3. 三种结果：
   - **可用**：直接占用该名称，然后按 `02-备案信息表.md` 提交备案。
   - **被占用 / 与已有名称近似**：换用下面的备选名；一旦换名，全部材料同步改。
   - **需要证明材料**：如果提示与你的公众号/小程序同名或属于同一主体，按提示提交主体证明。

## 备选名（按推荐顺序）

| 名称 | 说明 | 风险 |
| --- | --- | --- |
| 鸭鸭鸭行动 | 现有项目名、README/在线试玩一致 | 在线演示站已用同名，若他人抢注则不可用 |
| 鸭鸭撤离行动 | 保留"鸭"和核心玩法"撤离"，辨识度高 | 需查重 |
| 鸭鸭搜打撤 | 直接点明搜打撤玩法 | 偏通用词，可能近似较多 |
| 鸭鸭岛行动 | 呼应地图"鸭鸭岛"设定 | 需查重 |
| 急撤鸭鸭 | 强调限时撤离的紧张感 | 偏口语 |

## 命名合规提醒（避免备案/提审被驳回）

- 名称中**不要**包含英文、"软件"二字、品牌名、公众人物名——IAA 游戏这类名称会触发额外要求提交《计算机软件著作权登记证书》或授权材料。
- 不要使用"最""第一""官方"等极限词。
- 名称长度建议 4–8 个汉字。
- 名称确定后，同步更新：`minigame/project.config.json` 的 `projectname`、`docs/wechat/02-备案信息表.md`、`03-隐私政策.md`、`04-用户协议.md` 里的游戏名。
