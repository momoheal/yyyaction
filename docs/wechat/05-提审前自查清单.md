# 提审前自查清单

> 微信官方规范：不得提交与小游戏后台开发模板相似度过高、换皮、抄袭的游戏；同一游戏多平台运营时，小游戏版本服务不得低于其他版本；不得在小游戏内引导用户转端。

## 一、工程与构建

- [ ] `minigame/project.config.json` 的 `appid` 已替换为你的真实小游戏 AppID
- [ ] `minigame/projectname` 为「鸭鸭鸭行动」
- [ ] 两个广告位 ID 已替换为 MP 后台创建的真实广告位 ID（首次提审可留空，UV > 500 后更新版本再填）
- [x] 运行 `npm run build:minigame` 成功，`minigame/game.js` 已更新（2026-11-23，整包 1.8 MB，`node --check` 通过）
- [ ] 用微信开发者工具「导入项目」打开 `minigame/` 目录，编译无报错
- [ ] 真机预览可完整走通：新手行动 → 正式行动 → 撤离/阵亡 → 复活 → 返回大厅

## 二、广告合规

- [ ] 激励视频只在用户主动点击时触发，无自动弹出
- [ ] 广告未看完不发放奖励；中途关闭不发放
- [ ] 广告加载失败有提示，且不卡死游戏
- [ ] 复活每局 1 次、领金币每日 5 次，有明确次数提示
- [ ] 广告位 ID 与实际投放的激励视频广告位一致

## 三、内容与备案一致性

- [ ] 游戏名称、账号主体、备案信息、提审信息四处一致
- [ ] 游戏介绍与实际玩法一致（单机、无内购、六个战区、三名角色、七名首领）
- [ ] 隐私政策、用户协议中的主体名称与联系方式已填写
- [ ] 提审截图为同一版本、尺寸一致，无调试信息

## 四、体验与性能

- [ ] 横屏布局在常见手机分辨率下无遮挡、按钮可点
- [ ] 触屏摇杆、自动开火、翻滚、换弹、治疗、手雷、搜索全部可用
- [ ] 后台切换（onHide）会自动暂停
- [ ] 连续游玩 10 分钟无明显卡顿或闪退

## 五、多平台一致性（后续上 TapTap/抖音/小红书时）

- [ ] 小游戏版本内容不低于其他平台版本
- [ ] 小游戏内不含引导用户去其他平台的文案或按钮
- [ ] 各平台独立提交，不共用同一份 AppID/广告位 ID
