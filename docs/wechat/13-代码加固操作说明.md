## 公钥配置完成后

在项目根目录运行：

```bash
npm run code-fortify:package
```

成功后会生成：

- `minigame-opt/fortify-output/game.js` — 加固后的入口
- `minigame-opt/fortify-output/game.js.map` — sourcemap（建议一并保留，线上报错可用于映射定位）
- `minigame-opt/fortify-output/game.json`
- `minigame-opt/fortify-output/project.config.json`

然后用微信开发者工具打开 **`minigame-opt/fortify-output`** 目录，真机预览确认能进游戏、能开局、能撤离，再上传提审。

## 注意事项

- 每次改了 2D 源码后，先跑 `npm run build:minigame-opt`，再跑 `npm run code-fortify:package`。不要直接在加固产物上改代码。
- 已加固的代码带有标记，不要手工修改；再次加固会自动忽略已加固文件。若要重新加固，先重新构建生成新的 `game.js`。
- `id_rsa.conf` 含私钥，必须留在 `.workbuddy/fortify/`，不要放进 `minigame-opt/dist` 或上传包。
- 若再次遇到 `-10000404`，说明后台公钥还没生效或 AppID 不对；若遇到 `-10000401`，说明前后台公私钥不匹配。
- daily 加固次数有限频（`-1100002`），不要反复空跑。
