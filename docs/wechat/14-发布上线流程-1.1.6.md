# 发布上线流程（版本 1.1.6）

> 更新：2026-11-27。代码侧已就绪：`1.1.6` 已上传为「开发版」，包体 995.8 KB，加固通过、开发者工具编译通过。
> 发布必须由账号管理员在微信公众平台（MP）后台操作，我无法代登录、代扫码、代提交。

## 一、先确认唯一的硬卡点：小游戏备案

微信规定：**小游戏备案未通过，不能提交审核，也不能发布。**

查看位置：MP 后台 → 「账号设置」→「小程序备案」/「小游戏备案」，看状态：

| 状态 | 下一步 |
| --- | --- |
| 未提交 | 先按 `02-备案信息表.md` 提交，等审核（约 1–2 周），期间不要改名称/主体 |
| 审核中 | 等结果；同时可先做下面第二节的准备工作 |
| 已通过 / 无需备案 | 直接进入第二节 |

> 开发版可以在真机试玩，不受备案影响；但「提交审核 → 发布」这一步必须有备案。

## 二、提审（备案通过后）

1. **确认上传的是哪一版**
   - MP 后台 →「管理」→「版本管理」→「开发版本」，应看到 `1.1.6`，备注为「装备页图标重做…」。
   - 若没有或想重传：微信开发者工具打开 `minigame-opt/fortify-output`（**加固产物**，不是 `dist/`），点「上传」，版本 `1.1.6`。

2. **提交审核**
   - 在 `1.1.6` 右侧点「提交审核」。
   - 依次填：功能页面/类目 → 游戏内容介绍 → 自审自查报告 → 版本更新说明 → 测试说明。
   - 文字全部在 `07-提审填写模板.md`，直接复制。本次版本说明用 1.1.6 那段。

3. **等审核**（通常 1–7 天，以后台通知为准）
   - 审核期间不要改名称、类目、主体。
   - 若被驳回，把驳回原因发我，我改代码或文案后重新上传。

4. **发布**
   - 审核通过后，后台「版本管理」会出现「审核通过版本」，点「提交发布」。
   - 首次发布建议先「全量发布」；也可先灰度（部分用户）观察崩溃率。

5. **上线后自查**
   - 用另一个非管理员微信搜「鸭鸭鸭行动」进入，走一遍：新手行动 → 搜刮 → 撤离 → 结算。
   - 确认无白屏、无卡加载页。

## 三、提审时容易被卡的 5 个点

1. **类目必须是「游戏」**，且内容介绍与类目一致（本作为动作/射击）。个人主体不要选文化互动、角色扮演、牌类。
2. **名称四处一致**：账号名称、备案名称、提审名称、游戏内标题都写「鸭鸭鸭行动」。
3. **未成年人保护**：小游戏需在后台完成实名与防沉迷相关配置（微信统一能力）。若后台提示「未接入健康系统」，按提示开启后再提审。
4. **不要出现调试痕迹**：截图/录屏里不能有 `__duck` 调试入口、控制台报错、二维码、联系方式。本次上传的是加固版，已去掉调试信息。
5. **广告按钮是禁用态属于正常**：首次提审广告位留空，按钮显示「广告位待配置」，不影响审核；UV 破 500 开通流量主后再更新版本。

## 四、上线之后

| 阶段 | 动作 |
| --- | --- |
| UV > 500 | 后台「功能 → 流量主」开通 → 建两个激励视频广告位（复活 / 金币）→ 把 `adunit-` ID 发我 |
| 拿到广告 ID | 我填进配置、重新构建上传 `1.2.0` 提审，通过后广告生效 |
| 后续迭代 | 每次改完我构建 + 加固 + 上传，你在后台提审发布 |
