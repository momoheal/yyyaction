# 微信小游戏后台备案与提审操作指引

> 前提：账号已完成实名认证、已开通游戏类目、名称已确定、备案已通过。若这些还没做，先从 `00-从零到提审行动清单.md` 开始。
> 最终提交必须由你在 MP 后台用管理员微信扫码完成，我无法代登录。

## 阶段 0：本地准备（已完成/按清单做）

1. `npm run build:minigame` 构建 `minigame/game.js`。
2. 微信开发者工具导入 `minigame/` 目录，AppID 填你的真实 AppID，编译并真机预览。
3. 按 `05-提审前自查清单.md` 全部勾选。
4. 按 `01-名称查重.md` 确认名称可用。

## 阶段 1：广告位（首次提审不需要，UV 破 500 后再做）

1. MP 后台 → 流量主 → 广告位管理 → 新建广告位。
2. 类型选「激励视频广告」，建两个：一个命名"复活"，一个命名"金币"。
3. 复制两个 `adunit-` 开头的 ID，填入 `src/minigame/config.ts` 的 `AD_UNITS.revive` 与 `AD_UNITS.coins`。
4. 重新 `npm run build:minigame`。
   - 流量主开通通常要求小游戏有一定用户量；若暂时无法开通，可把广告位 ID 留空并先提审无广告版本（游戏内按钮会显示"广告位待配置"，不影响审核），开通后再更新版本。

## 阶段 2：小游戏备案（上线前置）

1. MP 后台 → 账号设置 → 小程序备案 → 小游戏备案「前往提交」。
2. 按 `02-备案信息表.md` 填写，游戏类型选**单机**，变现类型选 **IAA / 不申请支付资质**。
3. 上传截图（按文档要求的尺寸与版本）。
4. 提交后等待平台初审 + 主管部门审核。审核中**不要**修改游戏名称或账号主体。
5. 小游戏备案通过后即可进入阶段 3 提审上线；后续再完善小程序备案。

## 阶段 3：提审发布

1. 微信开发者工具打开 `minigame-opt/dist`（**不要用旧的 `minigame/`**）→ 点击「上传」→ 填版本号（本次 `1.1.2`）和备注。
2. MP 后台 → 版本管理 → 开发版本 → 找到刚上传的版本 → 提交审核。
3. 填写：
   - 游戏介绍：复制 `02-备案信息表.md` 的"游戏内容介绍"。
   - 测试账号：本游戏无登录，填"无账号，可直接体验"。
   - 隐私政策/用户协议链接：把 `docs/wechat/03-隐私政策.md`、`04-用户协议.md` 发布到你的可访问网页地址，填入链接；或按后台要求上传文件。
4. 审核通过后，在版本管理点「发布」。

## 审核时间与常见结果

- 资质审核一般 1–3 个自然日；小游戏备案与版本审核时间以后台显示为准。
- 驳回时看具体原因：名称/主体不一致 → 撤回重填；内容介绍与截图不符 → 换同版本截图；广告相关 → 检查是否强制观看或奖励未发放。
- 提审被拒不要重复提交相同内容，先按驳回原因改。

## 上线后

- 上线后按 `05-提审前自查清单.md` 的"多平台一致性"部分，再规划 TapTap、抖音、小红书版本。
- 每次改代码都要重新上传+提审，不能只改后台。
