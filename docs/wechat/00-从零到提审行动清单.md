# 从零到微信小游戏提审：行动清单

> 更新：2026-11-23。工程侧已就绪：`minigame/` 整包 1.8 MB（低于 4 MB 主包上限），`game.js` 语法校验通过，网页版 `dist/index.html` 已重建。AppID 与广告位仍是占位符；账号、备案、AppID、名称查重仍待你在 MP 后台完成，因此**目前还无法提交审核**。
> 提审必须由你本人用管理员微信登录微信公众平台（MP）完成，我无法代登录、代扫码、代提交。

## 一个先要知道的事实：广告要等 UV 500

微信官方规则：开通流量主（才能创建激励视频广告位）需满足**任一**条件：

- 条件一：小程序累计独立访客（UV）> 500，无刷粉、无严重违规。
- 条件二：开通内置游戏圈并发布 5 篇官方帖且产生有效活跃。
- 条件三：同公司主体名下已有小程序已开通流量主、持续一个季度有变现且无违规记录。

个人主体和企业主体满足条件一后都能开通流量主。

**这意味着**：新账号刚上线时拿不到广告位 ID。推荐分两步走：

| 阶段 | 目标 | 广告处理 |
| --- | --- | --- |
| 第一次提审 | 先把游戏上线，拿到真实用户 | 广告位留空。游戏内按钮显示「广告位待配置」，核心玩法完全可玩，不影响审核 |
| UV 破 500 后 | 开通流量主 → 创建两个激励视频广告位 → 更新版本 | 填入复活/金币广告位 ID，重新构建上传提审 |

工程已经按这个方案做了兜底：广告位 ID 未配置时按钮禁用并提示，不会崩溃、不会卡流程。

## 阶段 1：注册小游戏账号（半天到 1 天）

1. 打开 <https://mp.weixin.qq.com> → 立即注册 → 小程序。
2. 邮箱需未注册过微信公众平台，激活邮箱。
3. 主体类型：你个人开发者选**个人主体**即可（IAA 广告变现不需要企业主体；只有虚拟支付/内购才需要企业）。
4. 注册完成后进入 MP 后台，**服务类目必须选「游戏」**。一级类目注册时勾选后不可修改，选错只能重注册；二级类目发布前可改，个人主体不能选文化互动、角色、牌类。
5. 在 MP 后台「开发 → 开发设置」复制 **AppID**（`wx` 开头），发给我，我填进工程。

## 阶段 2：名称查重（几分钟）

按 `01-名称查重.md` 在 MP 后台检测「鸭鸭鸭行动」是否可用。名称一旦提交备案并进入审核，就不能改，所以先查重。

## 阶段 3：小游戏备案（约 1–2 周，含主管部门审核）

1. MP 后台 → 账号设置 → 小程序备案 → 小游戏备案「前往提交」。
2. 按 `02-备案信息表.md` 填写：游戏类型选**单机**，变现类型选 IAA / 不申请支付资质。
3. 上传同版本、同尺寸的截图 5–8 张。
4. 审核期间不要改名称或主体。
5. 小游戏备案通过后即可提审上线；小程序备案后续再补。

## 阶段 4：提审上线（审核 1–7 天，以后台实际为准）

前置：备案已通过 + 你有真实 AppID + 工程已构建。

1. 把 AppID 发给我 → 我填入 `minigame/project.config.json` 并重新构建 `game.js`。
2. 你用微信开发者工具打开 `minigame/` 目录，点「上传」，版本号填 `1.0.0`。
3. MP 后台 → 版本管理 → 开发版本 → 提交审核。
4. 按 `07-提审填写模板.md` 填写游戏内容介绍、自审自查报告、版本更新说明等必填项。
5. 审核通过后，点「提交发布」→ 全量发布。

## 阶段 5：开通广告（UV > 500 后）

1. MP 后台 → 功能 → 流量主 → 开通（满足条件后次日刷新资格）。
2. 流量主 → 广告位管理 → 新建两个**激励视频广告位**：「复活」「金币」。
3. 把两个 `adunit-` 开头的 ID 发给我 → 我填入 `src/minigame/config.ts` 并重新构建。
4. 重新上传一个新版本（如 1.1.0）提审，审核通过后广告生效。
