# 你登录后按顺序做这 4 步

> 背景：浏览器自动化在这个环境里无法保持登录会话（每条命令后浏览器会重启），所以我没法稳定地"接着你的登录态"填表。
> 分工：**你负责在 MP 后台点击和粘贴，内容我已经全部写好，照抄即可。**
> 打开：<https://mp.weixin.qq.com> → 用微信扫码或「微信快捷登录」。

## 第 1 步：拿 AppID 发我（最重要）

登录后台后：

1. 左侧菜单 → **开发 → 开发设置**
2. 页面顶部找到 **AppID（小程序ID）**，`wx` 开头的一串字符
3. 把 AppID 复制发给我

我收到后立刻填进 `minigame/project.config.json`，重新构建 `game.js`，你就能用微信开发者工具上传代码了。

## 第 2 步：名称查重

1. 后台 → **设置 → 基本设置 → 名称**
2. 点「修改」或「检测」，输入 `鸭鸭鸭行动`
3. 结果处理：
   - 可用 → 记下，继续第 3 步
   - 被占用 → 看 `01-名称查重.md` 的备选名，挑一个告诉我，我同步改工程和所有材料

## 第 3 步：提交小游戏备案（上线前置）

1. 后台 → **账号设置 → 小程序备案 → 小游戏备案「前往提交」**
2. 逐项照 `02-备案信息表.md` 填；游戏类型选**单机**，变现类型选 **IAA / 不申请支付资质**
3. 主体信息按你账号实名的填
4. 截图 5–8 张：用微信开发者工具真机预览截，尺寸版本一致
5. 提交后等审核，期间不要改名称或主体

## 第 4 步：上传代码并提审

备案通过后：

1. 微信开发者工具打开 `minigame/` 目录（AppID 已由我填好），点「上传」，版本 `1.0.0`
2. 后台 → **版本管理 → 开发版本 → 提交审核**
3. 需要的文字全部在 `07-提审填写模板.md`：
   - 游戏内容介绍 → 直接复制第 2 节
   - 游戏自审自查报告 → 直接复制第 3 节
   - 版本更新说明 → 复制第 4 节的 1.0.0 那段
   - 测试说明 → 复制第 5 节
   - 游戏引擎 → 选「其他」，填「自研 Canvas 引擎（TypeScript）」
4. 提交审核，等微信通知

## 之后：接广告

首次提审**先别管广告**——新账号流量主需累计 UV > 500 才能开通。等达标后：

1. 后台 → **功能 → 流量主 → 开通**
2. 流量主 → **广告位管理** → 建两个激励视频广告位：「复活」「金币」
3. 把两个 `adunit-` 开头的 ID 发我 → 我填进 `src/minigame/config.ts` 重新构建
4. 上传 1.1.0 版本提审，通过后广告生效

## 你现在只要给我两样东西

1. **AppID**（第 1 步拿到）
2. **名称查重结果**（第 2 步，如果「鸭鸭鸭行动」被占用就告诉我备选）

其余内容我全写好了，你照着粘贴即可。
