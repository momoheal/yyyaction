## 需要新做的商店素材

### 图标

现有 `art_assets/wechat-avatar.png` 是 144×144，不足以作为 TapTap 要求的 512×512 或更高分辨率图标。建议从原始角色/Logo 素材输出一张至少 1024×1024 的直角方图主稿，再按各平台后台尺寸导出。TapTap 不接受自行裁切的圆角图标；抖音图标不要含二维码、联系方式、外部水印或误导性角标。

### TapTap 封面与推广图

- 横版游戏封面：460×215，PNG/JPG，3 MB 以内，需显示游戏 Logo 与标题。
- 16:9 宣传图：至少 1920×1080，PNG/JPG，4 MB 以内；只能放游戏名等平台允许内容，不可直接使用截图或简单拼贴。
- TapTap 实机录屏：MP4/MOV，至少 15 秒；建议剪成 30–60 秒，前 5 秒进入玩法，连续展示核心玩法。不要叠加其他平台水印、外链或导流内容。

### App Store 截图

当前 1280×720 网页图不能直接充当 iPhone 商店截图。先完成 iOS 构建，再从 iPhone 模拟器或真机截取横屏画面，并按 App Store Connect 当前接受尺寸导出；至少需要一张 iPhone with Dynamic Island（medium display）截图。若最终支持 iPadOS，还需提供 13 英寸 iPad 截图。

建议顺序：主战斗 → 搜刮 → 撤离 → 首领战 → 装备/仓库。截图应来自最终可审核包，不要用网页画面加设备边框来代替真实应用截图。

海外商店截图必须从英文界面版本重新截取。现有网页截图为简体中文，只能作为 TapTap 中文版候选素材，不能直接用于英文商店页；需等 `npm run build:en` 完成逐屏检查后，再从最终 iOS 构建录制英文画面。

## 实机视频脚本草案

适用于 TapTap 的首版录屏，可从实际游戏画面连续录制，控制在约 30 秒：

1. 0–5 秒：直接展示角色移动与交火。
2. 5–12 秒：打开物资箱并拾取装备。
3. 12–20 秒：展示首领或精英敌人的机制与躲避操作。
4. 20–30 秒：赶往撤离点并完成撤离结算。

录制时使用最终移动端触控版本，避免只展示标题、仓库或宣传画。

## TapTap 普通小游戏专项适配

- TapTap 真机小游戏不是普通网页/H5 环境。当前微信 `adapter.ts` 依赖 `wx.*` 并模拟部分 `window`/`document`；普通 Tap 小游戏运行时不提供完整浏览器 BOM，需要单独适配 Canvas、触控、存储、生命周期和音频。
- 按 TapTap 开发者工具输出平台要求的 zip 包，并集成 TapTap 登录。当前项目没有账号系统或服务端，登录凭证交换方案需先确定。
- 当前游戏内把金币和物资价值显示为 `¥`，TapTap 小游戏内容规范禁止现金符号。TapTap 版本应改为“金币”“价值”等纯游戏词，并重新截取所有出现该符号的截图。
- 当前微信激励广告接口不能复用；若保留广告奖励，接入 TapTap 支持的广告产品并更新隐私材料，否则关闭对应广告入口。
- TapTap 小游戏运行环境文档当前标注无网启动支持仍在开发；提审前须在联网环境完成启动和登录验证，这不改变游戏核心玩法为单机。
- TapTap 文档对包体上限（20 MB/60 MB）以及 ISBN 适用范围存在不同表述，正式准备包体和资质前按当前控制台提示或平台支持确认。

## 平台提审检查表

### App Store

- [ ] Apple Developer 账号、发行主体、Bundle ID 和签名配置完成。
- [ ] iOS 安装包可离线启动、横屏操作、后台切回后正常恢复。
- [ ] 上架地区所需资质和 App Store Connect 信息完成；中国大陆游戏核对审批号及适用 ICP 信息。
- [ ] 隐私政策有公开 URL，隐私标签覆盖应用及第三方 SDK。
- [ ] 年龄分级、内容版权、支持 URL、审核备注填写完成。
- [ ] 从最终 iOS 构建截取符合规格的商店截图。
- [ ] 海外商店页从英文构建对应的最终 iOS 包截取英文截图，核对界面无中文残留且文本未溢出。

### TapTap 普通小游戏

- [ ] TapTap 开发者认证及小游戏能力开通完成，创建游戏时选择“小游戏”，明确普通小游戏而非 H5。
- [ ] TapTap 运行时适配完成，打包工具生成 zip，登录在开发版本和审核版本均可正常工作。
- [ ] 完成小游戏前置备案；按开发者后台确认是否需提交版号、软著及授权链材料。
- [ ] 替换现金符号和微信广告入口；完成 TapTap 登录的隐私告知与服务器端凭证处理。
- [ ] 上传至少 3 张横版实机截图，截图与 TapTap 最终包一致；完成图标、封面、16:9 宣传图、简介、开发者的话、更新日志和实机录屏。
- [ ] 在联网环境通过 TapTap 开发工具自测并验证横屏、触控、存档、登录和广告状态。

### 抖音小游戏

- [ ] 创建抖音小游戏工程，替换微信 `wx.*` 适配层并接好 `tt.*` 能力。
- [ ] 按当前预检接入必接能力（包含侧边栏复访能力）。
- [ ] 完成小游戏备案/ICP 核准，取得 ICP 核准号；如有版号，核对后台同步的批文与授权材料。
- [ ] 图标、名称、10–60 字简介、版本说明和隐私材料与实机内容一致。
- [ ] 开发者工具预检、抖音客户端真机预览，并验证广告加载失败、离线存档、横屏和返回/切后台。
- [ ] 提审前根据平台审核路径确认版本是否还需合作宿主 App 的 QA 回归。
