# 鸭鸭鸭行动 · 优化版更新日志

> 基于原版 `鸭鸭鸭行动.html` 的完整改动记录。所有素材均为程序绘制（首领头像除外），改动均已通过代码语法检查与离线渲染检查，但尚未经过完整的实机试玩，数值部分请以实测为准。

---

## 一、新地图：冰火空军基地

- 新增第 7 张地图，排在霜锋哨站与鸭王陵寝之间，累计撤离 10 次解锁，难度「噩梦 · 冰火双首领」。
- 布局：北侧西翼机库、塔台、东翼机库；中央横贯全图的跑道（09/27 编号、中线、边灯）；南侧西半熔岩焦土、东半冰霜雪原，中间渐变过渡。
- 场景素材：机库、停放战斗机、雷达站、导弹架、沙袋墙、油罐、天线杆、熔岩池/裂缝、冰块/冰晶、石桥。
- 专属首领：**烈焰王牌**（熔岩区）与 **冰霜雷达官**（冰霜区），两者相距约 1880 像素。
- 3 个撤离点：塔台直升机坪、西侧运输机、中央停车场。

## 二、首领

### 新首领
| 首领 | 技能轮换 | 掉落 |
|---|---|---|
| 烈焰王牌 | 低空扫射（红色航线后连续爆炸，二阶段两条交叉航线）→ 凝固汽油弹（燃烧带）→ 扫射 → 加力冲刺 | 王牌飞行徽章、M134 火神炮 |
| 冰霜雷达官 | 雷达锁定（扫描扇形内被狙击，掩体可躲）→ 冰墙封锁（可击碎，8~10 秒消失，敌人会绕路）→ 冰霜地雷（踩中受伤减速）→ 锁定 | 极地雷达核心、冰风 MP9 |

### 原有首领新增技能
| 首领 | 新技能 |
|---|---|
| 鹅老大 | 鹅鸣音波（环形弹幕） |
| 铁钩船长 | 舷炮齐射（红圈预警炮击）、锚链横扫 |
| 炉心监工 | 熔渣泼洒（燃烧熔渣，不伤自己的小兵）、呼叫护甲工头 |
| 孵巢鸭后 | 母巢抛卵（爆炸蛋）、腐叶孢子（可用墙挡） |
| 霜羽元帅 | 霜影闪现（会预先标出落点）、冰棱环射 |
| 铁壁统领 | 重盾顿地、钢铁壁垒（回复护甲）；血量 1900→1600，护甲 280→260 |
| 鸭王 | 王命炮击、金币弹幕，共 6 招轮换；召唤数量 3/5→2/4 |

### 机制与修复
- 所有新技能都有预警：头顶技能名、地面红色虚线圈或航线、首领身上闪烁光环。
- 二阶段转换时取消正在准备的技能，停顿 0.8 秒并闪光震屏。
- 二阶段第二轮弹幕改用游戏内计时，暂停时会正确停住。
- 首领的扫射、炮击、熔渣不再伤到它自己召来的小兵。
- 修复所有首领召怪时都显示「孵巢增援！」的问题。
- **双首领地图**：霜锋哨站两首领间距 917→1547 像素，空军基地 1460→1880 像素。

### 首领外观
- 所有角色模型重画：描边、明暗、羽毛纹路、弧形鸭嘴、眼白和高光。
- 鹅老大、铁钩船长、炉心监工新增专属装备；孵巢鸭后头戴王冠（不再是旁边三颗蛋）；鸭王改为头戴星形金冠、手持权杖；铁壁统领改为头盔冠脊和弯角。
- 去掉了铁壁统领头像上那层深红色，恢复原画。
- 两位新首领头像用生图引擎按原有首领的卡通 3D 风格生成，统一朝右。

## 三、出生点与补给

- 所有出生点都在室外空地，并远离首领，最近距离 ≥ 735 像素；所有撤离点离最近出生点 ≥ 650 像素。
- **新增「补给箱」**：7 张图的每个出生点附近都有 2 个，绿色带白十字，检查过不压墙、不和其他箱子挤在一起。内容严格限定低级：
  - 武器：45% 概率出一把，只会是 M9 手枪 / MP5 / MP9
  - 药品：必出 1 个绷带，50% 再出 1 个，**不出急救针**
  - 投掷物：35% 概率，只会是破片手雷或烟雾弹
  - 护甲：40% 概率出一级护甲
  - 杂物：50% 概率出一件普通或优秀品质的物品

## 四、战利品

新增 34 种地图专属战利品，每张图 4~5 种，覆盖从普通到传说的各个品质。开箱时每件物品有约 24% 的几率换成本图专属物品，模拟 4000 个木箱后，各图专属物品的占比稳定在 22%~25%，不会出现别的图的专属物品。低品质的专属物品常见，高品质的稀有。

| 地图 | 专属战利品（从常见到稀有） |
|---|---|
| 鸭鸭岛 | 面包干粮、鸭鸭漫画、小黄鸭玩具、农场地契 |
| 盐雾货港 | 咸鱼干、海玻璃、船锚吊坠、铜船钟、黑珍珠 |
| 赤炉工厂 | 锈螺母、铜线卷、熔渣晶石、精密齿轮组、熔铸核心 |
| 腐叶孵化场 | 彩绘蛋壳、编织鸟巢、金羽毛、斑点鸭蛋、沼泽兰花 |
| 霜锋哨站 | 冻鱼、保温壶、永冻冰晶、雷达芯片、雪原勋章 |
| 冰火空军基地 | 航空铆钉、飞行员胸章、飞行日志、喷气发动机叶片、王牌头盔 |
| 鸭王陵寝 | 香烛、古铜钱、玉珠、玉玺、王室权杖 |

固定高级武器调整：工厂的火神炮、龙纹 AWM、传说 M4 换为轻机枪、狙击枪；孵化场、哨站、陵寝各减少一把 RPG。

## 五、地图布局

- **孵化场重做**：中央是木地板的鸭后巢穴竞技场，四面开口；环路加四条放射路；9 栋农场建筑；北侧池塘和东南排水沼泽各有木桥；新增西侧公交站撤离点。
- **后 5 张图补全空旷区域**：空格子比例从 31~58% 降到 16~30%，外圈加了树、石头、主题素材和少量搜刮箱、巡逻敌人。
- **全图素材清理**：删除 15 个摆错的素材，移动 37 个压墙、压树、压敌人站位的素材，修正 11 个嵌在墙里的敌人站位。
- **撤离点场景化**：每个撤离点脚下有对应场景（直升机坪、停车场、码头、快艇码头、铁路站台、闸门、牌坊、密道、下水道、排水闸、运输机）；货港、工厂、孵化场各新增一个撤离点。
- **7 座桥**：木桥和石桥都正确横跨水面，桥下可通行。
- **沥青公路**：货港、工厂、空军基地使用深色沥青路，平头接入跑道。

## 六、美术素材

- **新增程序素材**（全部俯视）：
  - 生活类：公交站、水桶、水井、邮筒、路灯、长椅、垃圾桶、晾衣绳
  - 军事类：雷达站（雷达盘会转）、导弹架、沙袋墙、油罐、天线杆
  - 场景类：孢子囊、香蒲、熔炉通风口、管线、冰晶塔、雪堆、符文柱、宫灯、货网、缆绳卷、浮标、铁锭堆、石狮、机库、跑道、停放战斗机、木桥、石桥
- **视角统一**：20 种原来带侧面的素材改为正上方俯视（告示牌保留）；带侧面的素材不再随意旋转，只允许左右翻转。
- 关闭了素材下方的通用暗色圆盘阴影。
- **可破坏木箱**：挡人挡子弹，60 点耐久，有裂纹，打碎后可穿过，约 18% 碎后露出可搜刮的「箱底暗格」；碎后敌人寻路也会更新。

## 七、画面与地面

- 墙体有立面、砖缝、投影，按地图区分材质。
- 室内地板去掉粗黑边框，改为靠墙渐暗、分缝和磨损。
- 每张地图独立的地面纹理（水渍、油污、苔藓、积雪、地砖），纹理尺寸 192→384。
- 每张地图的色调与天气粒子（货港雾、工厂火星、孵化场孢子、哨站飘雪、陵寝光点）。
- 素材发光（熔炉、宫灯、符文、冰晶等），改用缓存贴图提升手机性能。
- 货柜重画：侧面、瓦楞、角件、门缝锁杆、锈斑、编号；每张图独立配色。
- 哨站空地、空军基地熔岩焦土与冰霜雪原加了积雪、冰面、焦痕、裂缝、车辙和脚印。

## 八、界面

- **选图页面**：每张图用自己的主题色，只画大建筑并描边，去掉杂乱的小墙线条，撤离点和首领位置更醒目。
- **游戏内小地图**：保留墙体显示。
- **调试模式入口**：标题连点 5 次、Ctrl/Cmd+Shift+D、网址加 `?debug` 都会打开密码窗口；按钮改为直接校验，兼容大小写与全角字符。

## 九、已知问题 / 待测

1. 新首领与新技能的伤害、范围、冷却均为估算，未实测平衡。
2. 实体掩体的视野遮挡用圆锥阴影，形状未在实机确认。
3. 熔岩区只是装饰，踩上去不会掉血；空军基地冰霜那一半也在飘火星。
4. 可破坏木箱若紧贴墙，碎后可能误放开墙边一格寻路。
5. 鸭鸭岛、霜锋哨站、鸭王陵寝各有一个撤离点离出生点约 650 像素，略低于 700 像素标准。
6. 调试密码写在网页代码中，发布前建议移除快捷键与网址入口。
