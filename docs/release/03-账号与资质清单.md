## Apple Developer Program

- [ ] 创建或确认开启双重认证的 Apple Account。
- [ ] 选择个人账号或组织账号。个人账号商店卖家名称显示个人法定姓名；组织账号需合法实体、具备签约权限的账号负责人、D‑U‑N‑S 编号，以及组织域名邮箱和可用网站。
- [ ] 完成 Apple Developer Program 加入后，创建 App Store Connect 应用记录、Bundle ID 和签名配置。
- [ ] App Store 中国大陆：游戏需要游戏审批号；确认 ICP 备案是否适用并保证编号与备案主体/商店资料一致。
- [ ] App Store 海外：准备英文元数据、英文游戏内界面、英文隐私政策及支持页面；按目标国家/地区检查分级、版权和出口合规信息。

Apple 官方说明：[加入计划的个人与组织条件](https://developer.apple.com/programs/enroll/)、[中国大陆商店合规字段](https://developer.apple.com/help/app-store-connect/reference/app-information/app-and-compliance-information/)。

## TapTap 普通小游戏

- [ ] 注册并完成 TapTap 开发者/厂商认证，开通小游戏能力。
- [ ] 创建游戏时选择“小游戏”，并确认所用为普通 Tap 小游戏运行时，而不是 H5 版本。
- [ ] 准备游戏包、软件著作权人信息、游戏内容介绍、负责人身份资料及平台要求的补充材料。
- [ ] 完成小游戏前置备案。TapTap 创建指引称无内购小游戏不需提交版号，但其审核规范对版号另有更宽泛表述；以当前开发者后台对此包体和运营方式的审核口径为准。
- [ ] 当前版本使用激励广告且无内购；若保留广告，准备 TapTap 广告接入和对应隐私披露。不要把微信广告位 ID/接口当作 TapTap 广告配置。
- [ ] 核实 `momoheal` 权利人与 TapTap 账号运营主体、软著主体是否一致；不同主体需要按后台要求补齐授权链。

官方资料：[TapTap 小游戏资质说明](https://developer.taptap.cn/minigameapidoc/quick-start/guide/creation-improvement/)、[小游戏前置备案流程](https://developer.taptap.cn/minigameapidoc/quick-start/guide/pre-filing/)、[登录态管理](https://developer.taptap.cn/minigameapidoc/dev/tutorial/open-capabilities/login-management/)、[TapTap 小游戏审核规范](https://developer.taptap.cn/minigameapidoc/tap-operation/operation-standards/review-standards/)。

## 抖音小游戏

- [ ] 注册并完成抖音开放平台开发者主体认证。
- [ ] 准备小游戏名称、运营主体、负责人身份证明、软件著作权人/授权材料和与正式包一致的内容说明。
- [ ] 完成抖音小游戏备案与 ICP 核准；官方指引说明小游戏需取得 ICP 核准号后才能上线。若无游戏版号，走平台当前“小游戏备案 → ICP 核准”路径。
- [ ] 接入审核预检要求的必接能力，并用抖音客户端真机预览。
- [ ] 更新隐私政策：现有微信稿含微信存储和微信广告描述，抖音版需按最终 `tt.*` 接口和广告/登录 SDK 的数据处理重写。

官方资料：[抖音小游戏 ICP 核准指引](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/minigame/icp-filings)、[版本提审指引](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/minigame/examineguide)。

## 对接时还需提供的信息

1. 发行主体的计划：个人还是公司；如果公司，是否已有 D‑U‑N‑S 编号与可用官网。
2. 准备权利证明/授权材料，并确认材料中的权利人、发行主体和覆盖平台范围。
3. 是否继续在 TapTap 与抖音版本中投放激励广告；是否希望 TapTap 登录、云存档与本地排行榜互通。
