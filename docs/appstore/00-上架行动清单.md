## 三、接下来按顺序执行（你的待办）

### 步骤 1：确认权利与主体（审核硬门槛）
- 确认你是 `momoheal`（LICENSE 中的版权人）或持有覆盖商业发行的书面授权。
- 决定用个人还是组织 Apple 账号：个人卖家名显示法定姓名；组织需 D-U-N-S 与官网。
- 确认"Duck Duck Extraction 3D"名称在 App Store 可用（App Store Connect 里查重）。

### 步骤 2：建 App Store Connect 记录
- 创建 App，选 iOS，填名称、语言、Bundle ID（如 `com.yourteam.duckduck3d`）、SKU `duckduck-extraction-3d-v1`。
- 生成 **App Store Connect API Key**（.p8 + Key ID + Issuer ID），下载妥善保存。

### 步骤 3：托管两个网页（必须公开 HTTPS）
- 打开 `02-隐私政策.html` 和 `03-支持页.html`，替换所有 `[[PLACEHOLDER]]`（主体名、邮箱、日期）。
- 托管到任意公开 HTTPS 静态托管（GitHub Pages、Netlify、Vercel、你自己的站点均可），拿到两个 URL，填进 App Store Connect。

### 步骤 4：Capacitor 套壳（可在本 Windows 上先做前半段）
按 `04-WebView套壳与云构建方案.md` 第四节：
```bash
cd three-game
npm install @capacitor/core @capacitor/cli @capacitor/ios
npx cap init "Duck Duck Extraction 3D" com.yourteam.duckduck3d --web-dir=dist-en
npm run build:en
npx cap add ios
```
把整个 `three-game/`（含 `ios/` 和 `capacitor.config.json`）推到你的 Git 仓库。

### 步骤 5：Codemagic 云构建（无需 Mac）
- 注册 Codemagic（个人方案每月 500 免费分钟）。
- 连接 Git 仓库，添加 `codemagic.yaml`，配置 Apple API Key、证书、描述文件。
- 触发构建 → 自动签名 → 上传 IPA 到 App Store Connect。
- 首次构建失败多因签名配置，按 Codemagic 日志提示调整（常见：Bundle ID 不一致、描述文件缺能力）。

### 步骤 6：真机验证并从正式 IPA 重截截图
- TestFlight 安装，核对：启动、新手引导、搜刮、交火、撤离、切后台恢复、横竖屏、音频、触屏双摇杆。
- 按 `05` 的规格，从真机重截 5–6 张英文截图替换本目录候选。

### 步骤 7：填 App Store Connect 并提交审核
- 商店信息照 `01-英文商店文案.md` 填。
- 隐私标签：按"不收集数据"填（应用无网络、无 SDK、无账号、无广告、无内购；本机存档属设备本地数据，通常不列为收集）。
- 年龄分级问卷：卡通暴力，通常 9+/12+，按实际勾选。
- 审核备注填 `01` 里的 Review Information。
- 版权：`Copyright © 2026 <你的主体>. All rights reserved.`
- 提交审核。

## 四、上架前必须做到的三条红线

1. **不能以调试版提审。** 线上 WorkBuddy 分享链接目前是上一轮的"默认调试模式开启版"，但那是网页版；3D 源码本地已是干净版。套壳务必用 `dist-en`（或 `dist`）重新 `npm run build` 的产物，不要用任何带 `debugMode`/全图解锁的旧快照。
2. **隐私材料 URL 必须真实可访问**，且内容与最终包一致（本游戏确实零网络、零 SDK，文案据实写，审核问答也照此填，不要自相矛盾）。
3. **海外版别混入中文**：截图和描述都已英文；`i18n.ts` 已补齐。若后续再改游戏加新文案，记得同步补英文词条。
