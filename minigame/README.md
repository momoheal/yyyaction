# 微信小游戏工程

此目录是《鸭鸭鸭行动》的微信小游戏原生工程，由 `src/minigame/` 源码和 `src/game/` 游戏核心构建而成。

## 文件

- `game.js` — 构建产物（唯一入口，约 155 KB）
- `game.json` — 小游戏配置（横屏）
- `project.config.json` — 项目配置，需替换 appid
- `README.md` — 本文件，不参与打包

## 发布前必改一处

1. `project.config.json` → `appid`：换成你的真实小游戏 AppID。

广告位可留空先提审：新账号流量主需累计 UV > 500 才能开通，届时再把两个广告位 ID 填入 `src/minigame/config.ts` 的 `AD_UNITS`（复活、金币），重新构建上传新版本。未配置时广告按钮会禁用并提示「广告位待配置」，核心玩法不受影响。

改完运行（在项目根目录）：

```bash
npm run build:minigame
```

## 用微信开发者工具打开

- 工具 → 导入项目 → 目录选本 `minigame/` 文件夹 → AppID 填你的真实 AppID。
- 编译后可在模拟器/真机预览。上传前请按 `docs/wechat/05-提审前自查清单.md` 逐项检查。

## 广告设计

| 场景 | 触发方式 | 奖励 | 限制 |
| --- | --- | --- | --- |
| 阵亡复活 | 阵亡结算前弹窗，可选放弃 | 原地复活，60% 生命、30% 护甲，清除附近敌人与子弹 | 每局最多 1 次 |
| 领取金币 | 大厅 / 结算页按钮 | ¥20,000 | 每日最多 5 次 |

广告必须完整观看才发奖；中途关闭不发奖；加载失败有提示且不卡死。

## 本地数据与合规

存档用 `wx.setStorageSync`，不上传服务器、不收集个人信息。配套隐私政策、用户协议与备案材料在 `docs/wechat/`。
